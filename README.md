### 🔭 What I'm building now

**Multi-agent systems.** Orchestration written from scratch on the Anthropic API. Panels of specialised agents that debate, critique and adjudicate rather than answer once. My largest runs ~9,400 lines behind **636 passing tests**, with adversarial verification and structured termination rather than a fixed round count.

**LLM infrastructure and agent tooling.** Persistent cross-session memory over a hosted database, an MCP server exposing it to any client, generated per-project agent configuration, and the guardrails around all of it: pre-flight hooks that block unsafe operations before they run.

**Applied AI products.** Voice-to-structured-data capture for clinical practitioners. Retrieval-augmented generation over private corpora. Vision-model OCR turning handwritten field notes into structured records inside a live offline-first app.

**Machine learning.** PyTorch / Lightning. Sequence models and gradient boosting for forecasting and classification, built to report calibrated uncertainty rather than bare point estimates.

### 🧪 How I work

Test-driven · isolated experiments · reproducible configs · locked test sets · pre-registered thresholds · calibrated uncertainty · honest reporting.

A result isn't a result until it re-derives from its artifacts and survives a check for what else could explain it, including the checks that kill my own claims. I report the benchmarks I don't beat alongside the ones I do. That discipline is the part that transfers to any domain.
